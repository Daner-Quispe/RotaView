# RotaView
## Registro de Viagens - Transporte Urbano
> Este projeto consiste em um sistema de cadastro e exibição de rotas viajadas utilizando diferentes tipos de transporte urbano.

O usuário pode cadastrar e consultar viagens, informando a linha utilizada, o tipo de transporte, ponto de partida, destino e horário da viagem.
